# PolicyRAG

面向企业内部制度文档的权限感知问答系统。

## 第一版目标

支持管理员上传 PDF 和 Markdown 制度文档，普通员工在自己的知识库权限范围内提问。系统从授权资料中检索证据，返回带页码和章节定位的答案；没有可靠依据时明确拒答。

## 第一版范围

- 管理员和普通员工两种角色
- 知识库创建与用户授权
- PDF 和 Markdown 文档上传
- 文档解析、章节分块和页码定位
- 中文 Embedding 与 pgvector 向量检索
- BM25 或 PostgreSQL 全文检索
- 混合检索和结果追踪
- 权限在检索之前生效
- 回答来源编号和引用校验
- 无依据问题拒答
- 40 题固定评测集
- Docker Compose 本地启动

## 暂不实现

- Agent 工具调用
- Text-to-SQL
- 企业数据库和 SaaS 连接器
- 多种大模型供应商
- 复杂度量角色、计费与 Webhook
- 大规模并发和分布式索引

## 主流程

```text
管理员上传文档
  -> 系统解析并生成分块
  -> 分块生成向量和关键词索引
  -> 员工在授权知识库中提问
  -> 系统完成混合检索
  -> 回答模块生成带引用的答案
  -> 界面展示来源和原文位置
```
